How to add a new campaign

  1. Copy templates/base-template.html to campaigns/YYYY-MM-short-name/index.html
  2. Edit the copy — keep the $[FNAME|friend]$ and $[LI:UNSUBSCRIBE]$ merge tags
  3. Commit & push; Coolify auto-deploys
  4. Add a card here and import the page URL into Zoho Campaigns
